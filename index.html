How I work

A few things I built at the day job

Details are under NDA, so here is the engineering, not the business data.

01

Contract-first APIs that can't drift

Problem
Hand-written controllers and DTOs slowly diverge from the published API spec.
Built
OpenAPI specifications generate Spring controllers and DTOs through a custom SpringCodegen extension.
Result
Specification and code cannot drift apart; the contract is the source of truth for frontend and QA.
02

Localization across API, storage and events

Problem
Translations lived in legacy columns and weren't reliably propagated through events.
Built
Moved service logic to translation tables, dropped legacy columns, hardened event processing with a DLQ and deletion handling.
Result
End-to-end localization with failed events captured instead of lost.
03

Runbooks for PostgreSQL with CDC

Problem
Aurora PostgreSQL with Debezium CDC and serverless functions had no written recovery procedures.
Built
Runbooks for failover, backup/restore, replication slot recovery and safe schema changes; alarms routed to incident management.
Result
On-call has a tested path for the scary incidents, plus AI-assisted (MCP) tooling for log analysis.
04

Safer delivery pipeline

Problem
Broken migrations surfaced only at deploy, and the BDD template let failing scenarios pass silently.
Built
Added a Flyway migration dry-run to CI and fixed the Cucumber template so failures are actually reported.
Result
Broken migrations and broken scenarios now fail the pipeline instead of production.
